# UniSearch Website

这是 **UniSearch**（现代化跨平台 AI 自主内容调研与数据采集工作台）的官方静态展示与下载网站。

---

## ✨ 核心特性

- **设计美学**：极简高级科技风格，克制留白，支持温暖浅色工坊模式与黑曜石深色模式。
- **信源与技能矩阵**：
  - **32 平台独立连接器**：覆盖社交自媒体 (7)、AI 网页问答 (7)、全网搜索引擎 (7)、科技与商业资讯 (4)、垂直招聘与维权 (5)、实用解析工具 (2)。
  - **7 大预置业务技能**：销售课程情报、新媒体调研、品牌GEO与风险监测、薪酬基准、全网搜索聚合、创作者全量采集、全网无水印解析。
- **智能系统识别**：自动检测访客操作系统（macOS / Windows）并智能推荐安装包。
- **全平台下载专区**：
  - **macOS**：Apple Silicon (M系列) 与 Intel 架构 `.dmg` 安装包及权限修复指引。
  - **Windows**：64 位安装包 `.exe` 与免安装绿色版 `.zip`。
  - 提供 GitHub Releases 官方源与国内高速加速通道。
- **Local-First 架构呈现**：系统架构四层流转、引用式精准 RAG 与实体图谱可视化展示。

---

## 🚀 本地预览

本项目采用原生轻量纯静态架构（零构建步骤，开箱即用）：

```bash
# 方式 1: 使用 npx serve
npx serve .

# 方式 2: 使用 Python HTTP Server
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080` 即可预览。
